## Задание на пересдачу Go

Реализовать HTTP-сервис, который принимает POST-запросы в формате JSON, запускает команды с указанными аргументами (`cat`, `ls` и пр.) и выдаёт их результат (вывод stdout) в виде простого текста.


Некоторые команды могут выполняться долго, и для этого в запросе предусмотрен параметр `timeout`, который ограничивает максимальное время выполнения команды (в секундах). Кроме того, у самого сервера должен быть ограничитель сверху на максимальное время выполнения команды.


Формат запроса:
```json
{
    "command": [str, str, ...] /* команда и её аргументы */,
    "timeout": int, /* таймаута выполения в секундах */,
}
```

В случае, если команда успешно выполнена, нужно выдать ответ простым текстом и HTTP статус 200.
Если команда выполнялась дольше, чем `timeout` - HTTP статус 408.

Сервер запускается с аргументами командной строки:
 1. Адрес для прослушивания
 2. Целое положительное число - максимальное время выполнения любой команды (в секундах)
 
Кроме сервиса, необходимо реализовать 3 теста:
 1. Проверяющий успешный запуск команды
 2. Проверяющий обработку неверно сформированного запроса
 3. Проверяющий запуск команды в ситуации, когда она не заканчивается в отведенное время

Все файлы реализованного проекта необходимо выложить в git-репозиторий.
